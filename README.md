# Coffee Shop Order Tracker

A simple Python application using **Object-Oriented Programming (OOP)** to show how customers order coffee at a shop. You can:

- Track all orders.
- Return a list of unique coffees that a customer has ordered
- Create a new order for a customer
- Link each order to a customer and a coffee.
- Calculate who spent the most on a specific coffee.
- Get average prices and unique customers for each coffee.
- 	Return unique customers who ordered a coffee
- Get number of times this coffee was ordered

## KEY CONCEPTS
* Encapsulation: Uses private variables like _coffee, _price, _customer.
* Class Relationships: Each Order is linked to a Customer and a Coffee.
* Data Validation: Ensures correct types (e.g., price must be a float).
* Aggregation: Calculates stats like average price.
